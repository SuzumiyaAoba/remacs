face=bold の abc を append-to-buffer で別バッファへ送ると、GNU は全ての文字の face を保持するが remacs は全て nil にする。同条件の copy-to-buffer / prepend-to-buffer は保持する。append-to-buffer の Rust 実装だけが属性なしの String を使っている。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
