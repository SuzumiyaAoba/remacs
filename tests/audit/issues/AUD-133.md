起動環境の SHELL=/bin/zsh をGNUはshell-file-nameへ反映するが、remacsは /bin/sh に固定される。同じ環境の新規バッチプロセスで、環境変数と変数値の組はGNUが (/bin/zsh /bin/zsh)、remacsが (/bin/zsh /bin/sh) となる。shell-command-to-string 等の実行シェルと解釈規則が意図せず変わる。shell-file-nameを明示的に /bin/sh へ束縛する対照ケースの実行結果は一致する。初期値の登録が環境を参照せず固定文字列になっている。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。

             (list 'ok (eval '(list (or (getenv "ESHELL") (getenv "SHELL") "/bin/sh") shell-file-name) t))
