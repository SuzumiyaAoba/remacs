横に二分割した構成を保存して直ちに復元するだけで、GNU は window-left-child を保つが remacs は window-top-child に置き換える。右側だけを縦分割した入れ子も、全ての leaf が同じ親を持つ構成になる。保存した矩形は残る一方で、それを表すウィンドウ木の向き・親子関係が崩れる。復元処理が複数 leaf を常に一つの縦の内部ノードへ接続している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
