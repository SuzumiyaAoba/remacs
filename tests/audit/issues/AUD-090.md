tab-width=4 では GNU の char-width と string-width は TAB を 4 桁と数える。remacs は char-width では 4 を返すが string-width では 8 を返す。string-width の補助関数 gnu_char_width が TAB の幅を 8 に固定している。#147 の current-indentation とは別の実装箇所。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
