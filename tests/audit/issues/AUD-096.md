GNU の string-to-vector は vconcat 相当で、リスト、ベクター、bool-vector も新しいベクターへ変換する。remacs はいずれも wrong-type-argument stringp を送出する。入力を nil または文字列に限定している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。

## 再現手順

結果に含まれる制御文字は、読みやすいよう 8 進エスケープで表示する。

以下を `AUD-096.el` として保存する。

      (print-escape-control-characters t))
  (prin1 (condition-case err
             (list 'ok (eval '(string-to-vector '(1 2)) t))
           (error (list 'error err))))
  (terpri))

;; 'string-to-vector:vector'

      (print-escape-control-characters t))

             (list 'ok (eval '(let* ((source (vector 1 2)) (out (string-to-vector source))) (list (eq source out) out)) t))
           (error (list 'error err))))
  (terpri))

(let ((print-circle t) (print-escape-newlines t)
