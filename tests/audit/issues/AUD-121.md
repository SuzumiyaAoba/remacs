履歴が位置 2 への移動だけの場合、GNU は undo 履歴を増やさないが remacs は (apply cdr nil) を追加する。GNU がこの補完を行うのは apply エントリを実行して履歴が増えなかった場合だけだが、remacs は通常の位置エントリでも did_apply を true にする。apply エントリで補完が必要な対照ケースは一致する。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
