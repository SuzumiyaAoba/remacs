key-parse の反復指定が展開されない。GNUの 3*C-x は C-x を三つ、2*a は a を二つ返すが、remacsは 3、*、C、-、x および 2、*、a の各文字コードを返す。同じキーを空白で並べた対照ケースは一致する。キー設定・キーボードマクロで使う有効な記法が別のキー列として解釈される。単語ごとのパーサーに反復数と * を分離する処理がない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
