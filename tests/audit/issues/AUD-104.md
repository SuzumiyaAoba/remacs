PRINTFLAG=nil のとき GNU は評価中の princ の出力を捨てるが、remacs は呼び出し元の standard-output へ出す。PRINTFLAG にバッファを指定しても remacs はその出力先を使わず、GNU が指定先に送る通常出力と評価結果の表示も再現しない。両評価関数が PRINTFLAG を処理せず eval_str_buf を呼んでいる。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
