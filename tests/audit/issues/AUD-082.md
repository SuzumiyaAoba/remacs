[abc] の abc に narrow した状態で全バッファの範囲 1..6 を指定すると、GNU は args-out-of-range を送出し宛先を変更しない。remacs は指定範囲を全テキスト長に clamp して [abc] をコピーする。#17 の insert-buffer-substring 側とは別に、append-to-buffer 自身の Rust 実装にも可視範囲の検査がない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
