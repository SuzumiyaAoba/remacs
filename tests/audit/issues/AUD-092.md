最初の a だけに face=bold を持つ abc を nreverse すると、GNU は属性のない cba を返すが remacs は最後の a に bold を残す。reverse の同条件の対照ケースは両実装で属性なしになる。nreverse の文字列分岐だけが属性の区間を反転して新しい文字列へコピーしている。#250 の unibyte のバイト値変化とは異なる属性処理の問題。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
