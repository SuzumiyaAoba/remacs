text-scale-increase を呼んで autoload を発生させても、明示的に (require 'face-remap) しても、minor-mode-alist に text-scale-mode と buffer-face-mode が登録されない。GNU はそれぞれ登録するため、モードラインの有効状態表示等に使う情報が失われる。prelude は起動状態を合わせるため両モードの登録を消すが、lisp/face-remap.el は provide だけのファイルなので、ロード時にもその初期化を戻さない。files-x の公開APIと明示 require の対照ケースは一致し、全体コーパスの別の内部関数の遅延ロード差とは分けて確認した。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
