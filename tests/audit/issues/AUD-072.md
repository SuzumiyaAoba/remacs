face=bold を持つ abc の b を delete-region で削除して primitive-undo すると、文字は復元されるが b の face が nil になる。GNU は三文字とも bold を保持する。削除履歴を属性のない String として保存し、undo 時にも文字列の属性を挿入していない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
