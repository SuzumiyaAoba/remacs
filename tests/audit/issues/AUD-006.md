(lambda (x) (lambda () x)) を native-compile して 7 を渡すと、返された関数の呼び出しが void-variable x になる。GNU は 7。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
