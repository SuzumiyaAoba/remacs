同じ PTY 子プロセスへ 128000 文字を送ると、GNU は全量を届ける。remacs の process-send-string も正常に戻るが、この検証で子プロセスが受け取ったのは 1022 文字だけだった。proc_write の Child 分岐は write の戻り値が負でなければ成功とし、短い書き込みの残りを送らない。受信量は OS のバッファ状態に依存する。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
