make-pipe-process に渡したバッファを kill した後、GNU の process-buffer は同じ kill 済みオブジェクトを返すが remacs は nil を返す。元のバッファ参照との eq が GNU の t に対して nil になる。#54 の新規プロセスの sentinel / marker の既定値とは異なる寿命管理の問題。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
