選択ウィンドウに window-scroll-functions を設定して run-window-scroll-functions を明示的に呼ぶと、GNU は WINDOW・開始位置・対象バッファの文脈でフックを実行するが remacs は何もしない。split-window 後の新しいウィンドウへの通知もない。Rust の関数がウィンドウ引数の検査だけで nil を返している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。

## 再現手順



以下を `AUD-122.el` として保存する。

```elisp
;;; -*- lexical-binding: t; -*-

;; 'window-hooks:explicit-scroll-functions'
(let ((print-circle t) (print-escape-newlines t)
      (print-escape-control-characters t))
  (prin1 (condition-case err
             (list 'ok (eval '(save-window-excursion (let ((buffer (generate-new-buffer " *audit-scroll-hook*"))) (unwind-protect (progn (delete-other-windows) (switch-to-buffer buffer) (insert "one\ntwo\n") (goto-char 1) (set-window-start nil 1 t) (let ((window (selected-window)) hits) (let ((window-scroll-functions (list (lambda (w start) (push (list (eq w window) start (eq (current-buffer) buffer)) hits))))) (run-window-scroll-functions window)) (nreverse hits))) (kill-buffer buffer)))) t))
           (error (list 'error err))))
  (terpri))

;; 'window-hooks:split-notification'
(let ((print-circle t) (print-escape-newlines t)
      (print-escape-control-characters t))
  (prin1 (condition-case err
             (list 'ok (eval '(save-window-excursion (let ((buffer (generate-new-buffer " *audit-split-hook*"))) (unwind-protect (progn (delete-other-windows) (switch-to-buffer buffer) (insert "one\ntwo\n") (goto-char 1) (let ((window (selected-window)) got) (let ((window-scroll-functions (list (lambda (w _start) (setq got w))))) (let ((new (split-window window nil 'right))) (list (not (null got)) (eq got new)))))) (kill-buffer buffer)))) t))
           (error (list 'error err))))
  (terpri))
```
