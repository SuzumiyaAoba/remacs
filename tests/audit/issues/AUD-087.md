unibyte の (128 255) を ASCII または 233 で埋める操作は GNU では成功するが remacs は error になる。反対に multibyte の ASCII 文字列を 233 で埋める操作は GNU のバイト長変更エラーにならず成功する。明示的な unibyte/multibyte 状態を参照せず all_ascii で保存形式を判定している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
