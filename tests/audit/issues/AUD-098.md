case table で X と y を大文字・小文字の組に設定すると、GNU の char-equal と IGNORE-CASE=t の compare-strings は等しいと判定する。remacs は upcase では設定を認識するが、char-equal は nil、compare-strings は -1 を返す。search-forward、re-search-forward、string-match でも同じ組を見つけられない。標準の対応でも compare-strings は ß と S を GNU と異なり等しいと判定する。比較・検索が現在の GNU case table ではなく Rust の Unicode 既定の変換を使い、compare-strings は複数文字への大文字化の先頭だけを取っている。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
