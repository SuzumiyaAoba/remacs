(unibyte-string 128 255) に face を付けるだけで、aref・string-to-list・vconcat が返す値が (128 255) から (4194176 4194303) に変わる。multibyte-string-p は nil のままなので表面のフラグだけでは検出できない。propertize が文字列を複製する際に元のバイト表現に関するメタデータを引き継いでいない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
