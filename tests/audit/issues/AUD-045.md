1e30 秒を指定すると GNU は catch 可能な file-error。remacs は Duration::from_secs_f64 が panic して AUDIT-DONE に到達せず、main が join のエラーを無視するためプロセスは 0 で終了する。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
