リストを渡した場合、GNU は新しいリストを返すが remacs は元と eq のリストを返す。このため戻り値を setcar すると元のリストまで変わる。また (1 . 2) は GNU の listp エラーにならずそのまま返る。Cons 分岐が GNU の append 相当のコピー・検査を行わず入力を返している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
