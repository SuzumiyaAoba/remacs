macroexpand・macroexpand-1・macroexpand-all に文字列の FORM とリストではない ENVIRONMENT を渡すと、GNU は FORM をそのまま返すが remacs は listp の型エラーになる。例えば (macroexpand "x" "bad") は GNU の "x" に対して wrong-type-argument。マクロ探索のないアトムでも入口で ENVIRONMENT を無条件に検査している。実際にマクロを含む FORM で不正な環境を使う対照ケースは、両方とも wrong-type-argument になり一致する。#10 の load における再帰展開不足とは別の引数検査の問題。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
