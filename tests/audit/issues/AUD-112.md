prefix ab suffix の ab だけに narrow し、a と b を捕捉してから widen して \2\1 に置換すると、GNU は prefix ba suffix、remacs は prefix rp suffix になる。narrowing を保ったままなら一致する。置換の参照元を現在の BEGV から取得し、検索時の match data の base とずれるため、prefix の別の文字を参照する。FIXEDCASE=t の再現なので既存 #7 の大文字・小文字変換とは別。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
