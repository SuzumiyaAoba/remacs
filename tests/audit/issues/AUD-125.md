横分割した各ウィンドウの normal width、縦分割した各ウィンドウの normal height は、GNU では親に対する比率で 0 より大きく 1 より小さくなり、兄弟の合計は 1.0 になる。remacs は全て 1.0 なので合計も一致しない。分割と直交する方向の 1.0 は一致する。実装が木やサイズを参照せず定数を返しているため、サイズ復元等が使う比率を取得できない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
