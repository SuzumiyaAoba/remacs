NBSP または CR だけを含む行で delete-blank-lines を実行すると、GNU はその行を残すが remacs は文字ごと行を削除する。通常の空白と TAB の行では一致する。空行判定に Rust の trim().is_empty() を使い、GNU が空行とは扱わない文字まで空白として除去している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
