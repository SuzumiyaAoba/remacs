window-persistent-parameters で保存対象に指定したパラメータを 1 から 2 に変えて構成を復元すると、GNU は保存値 1 に戻すが remacs は 2 のままになる。構成保存がパラメータの可変 plist を clone して参照共有し、set-window-parameter の値セル更新が保存済みの構成にも反映される。保存対象外のパラメータをそのまま保つ二つの対照ケースは一致する。#277 の point・スクロール等のフィールド復元漏れとは異なり、パラメータは復元処理があっても保存値自体が変わっている。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
