abcde の末尾だけを置換しても、変更していない文字にある marker が先頭へ移動し、point も末尾へ飛ぶ。完全に同じ文字列での置換でも、GNU が保持する未変更状態と空の undo 履歴が失われる。差分を反映せず指定領域を丸ごと delete/insert している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
