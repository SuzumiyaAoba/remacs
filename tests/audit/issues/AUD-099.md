GNU Emacs で有効な内部文字コード 0x110000 と 0x110001、surrogate の 0xD800 と 0xD801、八ビット文字 0x3FFF80 と 0x3FFFFF が、case-fold-search=t だと全て等しいと判定される。GNU は全て nil。case-fold-search=nil の対照ケースは一致する。Rust の char::from_u32 が失敗した二つの None 同士を等しいと比較している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
