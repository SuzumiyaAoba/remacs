GNU の window-old-buffer は前回 window change functions が実行された時点のバッファを示すため、set-window-buffer だけでは値を変えない。remacs は set-window-buffer のたびに直前のバッファへ変更する。同じウィンドウで変更前の値を保持するかと直前のバッファを返すかを比較すると、GNU の (t nil) に対して remacs は (nil t) になる。表示変更通知を判定する履歴が早すぎる時点で更新される。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
