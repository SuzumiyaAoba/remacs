UDP を指定したサーバーの状態が GNU の open に対し remacs は listen になる。make-network-process は :type を読み取らず TcpListener/TcpStream を作成するため、datagram の通信を行えない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。

## 再現手順



以下を `AUD-069.el` として保存する。

```elisp
;;; -*- lexical-binding: t; -*-

;; "network:datagram-socket"
(let ((print-circle t) (print-escape-newlines t)
      (print-escape-control-characters t))
  (prin1 (condition-case err
             (list 'ok (eval '(let ((p (make-network-process :name "audit-udp" :host "127.0.0.1" :family 'ipv4 :type 'datagram :server t :service 0 :noquery t :sentinel #'ignore))) (unwind-protect (list (process-type p) (process-status p)) (delete-process p))) t))
           (error (list 'error err))))
  (terpri))
```

```sh
./target/debug/remacs -Q --batch -l AUD-069.el
/path/to/emacs-31.1 -Q --batch -l AUD-069.el
```
