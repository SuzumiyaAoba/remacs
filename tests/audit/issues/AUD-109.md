delete-blank-lines は可視の空行ではなく隠れた次の空行を削除する。delete-horizontal-space は可視領域外の前後の空白まで削除し、delete-indentation は隠れた前の行まで結合する。いずれも GNU は narrowing を守る。走査に BEGV/ZV ではなく全テキストの範囲を使っている。just-one-space の同条件の対照ケースは一致する。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
