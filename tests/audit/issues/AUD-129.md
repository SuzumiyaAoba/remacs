run-at-time 0 で登録したタイマーは、GNU では sleep-for 0・sleep-for -1・sit-for 0 だけでは実行されない。remacs はいずれもタイマーを実行して hits を 0 から 1 に変える。正の待ち時間では両方とも実行する。sleep_firing_timers の secs <= 0 分岐が即座に返る代わりに timer_check を呼ぶため、待機しない呼び出しで予期しないコールバックと副作用が起きる。#199 は accept-process-output の JUST-THIS-ONE 引数による抑止であり、本件の待ち時間の境界とは異なる。
