iso-latin-1 指定でも入力バイト E9 は U+FFFD になり、送信する é は E9 ではなく UTF-8 の C3 A9 になる。set-process-coding-system は未定義名にも成功する。ファイル I/O の #14 とは別の入出力経路。 listener の coding 設定も accepted 接続へ継承されず、初期の UTF-8 設定になる。
