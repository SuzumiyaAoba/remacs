子で set-buffer すると親の current-buffer も変わる。親の一時的な special 変数束縛も子に漏れ、GNU の global が parent になる。実行文脈を保存・切替せず i.apply している。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
