rename-file は有効な symlink オブジェクトを missing として拒否する。一方、壊れた symlink が宛先の場合は nil の上書き許可でも rename/copy が実行される。GNU は宛先の既存エントリーを保護する。exists() がリンク先をたどることを区別していない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
