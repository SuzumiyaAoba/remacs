make-byte-code の戻り値に対する aset は GNU では wrong-type-argument arrayp になる。remacs は命令文字列スロットと定数ベクタースロットを直接書き換え、関数の戻り値も変わる。aref で読み取れることと、aset で変更できることの区別がない。#121 の不正な byte-code 命令・定数アクセスとは異なる API の型検査の問題。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
