window-state-get の parameters は GNU ではパラメータ名と値の alist だが、remacs は内部の flat plist をそのまま出力する。このため assq による読み取りが失敗する。window-persistent-parameters も参照せず、保存対象が nil の状態でもパラメータを出力する。さらに GNU 形式の alist を window-state-put へ渡すと内部 plist へ変換されず、値 1 を戻すべき window-parameter が nil になる。保存対象 t と writable、および正しい alist の入力で再現。#115 は minibuffer の最小サイズ差、#152 は引数検査・window-parameters の順序差であり、本件の保存形式と永続化設定とは別件。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
