ロック中に別スレッドが mutex-lock / mutex-unlock できる。二度ロックした同一スレッドが二度 unlock すると二度目はエラー。owner を無条件で上書きし、所有者比較と再帰回数がない。

対象: `29e7c960edec18a99107741c351d95444f8f6b18` / macOS / GNU Emacs 31.1 との同一再現コードによる比較。
