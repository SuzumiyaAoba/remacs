対話的に呼んだ関数が通常の funcall/apply でヘルパーを呼ぶと、そのヘルパー内でも called-interactively-p='any が t になります。GNU は直接の呼び出し元を検査して nil を返します。また非対話バッチで KIND='interactive も t になります。interactive_call_depth > 0 だけで判定しており、呼び出しフレームと KIND を区別していません。

対象: `926cbfc7fe1ddde28c53d0555be1f6b99563535b` + 調査時の shell/display に関する既存作業ツリー変更、macOS/aarch64、GNU Emacs 31.1。新しくビルドした固定バイナリ SHA-256 `37aec7800115143d785086fa184114757237776c93c892e30696644b5c255017` で個別検証。旧38af4d1でも同じ結果でした。
