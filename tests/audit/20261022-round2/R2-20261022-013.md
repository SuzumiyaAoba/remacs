起動直後の Common Lisp モードは font-lock-defaults=nil になり、defun や関数名が構文強調されません。lisp-indent-function も common-lisp-indent-function ではなく Emacs Lisp 用のままで、字下げ結果が異なります。find-tag-default-function、Common Lisp コメント設定も欠けています。親の lisp-data-mode 自体にも font-lock の初期化がありません。

(require 'lisp-mode) では直らず、明示的に (load "lisp-mode") するとGNUと同じ設定になります。prelude の折り畳んだ定義が GNU lisp-mode.el の初期化を省いています。

対象: `926cbfc7fe1ddde28c53d0555be1f6b99563535b` + 調査時の既存作業ツリー変更、macOS/aarch64。GNU Emacs 31.1 と固定バイナリ `37aec7800115143d785086fa184114757237776c93c892e30696644b5c255017` で各ケースを独立実行。

(with-temp-buffer (lisp-mode) (list lisp-indent-function (and font-lock-defaults t) find-tag-default-function comment-start-skip))
