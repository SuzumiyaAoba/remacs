face 付き文字列の末尾で newline を実行すると、GNU は改行にも face を継承しますが Remacs は属性を落とします。f_newline は insert_str_at_point で属性のない改行を挿入しています。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64。GNU Emacs 31.1 と各式を別プロセスで実行して比較。

## 再現

以下を repro.el として保存します。

```elisp
;;; -*- lexical-binding: t; -*-

;; insert:newline-inherit
(let ((print-escape-newlines t))
  (prin1 (condition-case e (list 'ok (with-temp-buffer (insert (propertize "a" 'face 'bold)) (newline) (list (buffer-string) (get-text-property 2 'face)))) (error (list 'error e))))
  (terpri))
```

```sh
./target/debug/remacs -Q --batch -l repro.el
/path/to/emacs-31.1 -Q --batch -l repro.el
```

## 結果

`insert:newline-inherit`

```text
GNU: (ok (#("a\n" 0 2 (face bold)) bold))
Remacs: (ok (#("a\n" 0 1 (face bold)) nil))
```
