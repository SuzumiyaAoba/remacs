GNU は捕捉可能な Lisp error を返しますが、Remacs は Option::unwrap() on a None value で終了コード101になります。kill 済みバッファを受け付けた後の buffers.get(bid).unwrap() が原因候補です。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64、GNU Emacs 31.1 と同じ式を新規プロセスで実行して確認。
