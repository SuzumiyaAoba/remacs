1e9999 を GNU は json-number-out-of-range-error で拒否しますが、Remacs は正の無限大として成功します。JSON 入力の範囲検査が失われています。number の f64 パース結果に有限性検査がありません。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64、GNU Emacs 31.1 と同一コードで比較。`cargo build --offline --bin remacs` 成功。作業ツリーの既存 GUI 変更は保持しています。
