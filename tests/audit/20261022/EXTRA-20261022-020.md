GNU は STRING オブジェクトをそのまま補完関数へ渡し、関数の戻り値をそのまま返します。Remacs は入力文字列を Rust の文字列から作り直すため、eq とテキスト属性が失われます。test-completion では補完関数が返したリストも t に丸められます。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64。GNU Emacs 31.1 と各式を独立プロセスで比較。
