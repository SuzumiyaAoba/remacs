循環 Lisp オブジェクトを JSON に変換すると、GNU Emacs 31.1 は捕捉可能なエラーを返しますが、Remacs は循環 alist で無限ループし、循環 vector/hash-table ではスタックオーバーフローでプロセス全体を abort します。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64、各ケースを新規プロセスで単独実行。循環 alist は30秒で強制終了。vector/hash-table は returncode=-6 (SIGABRT)。

## 再現

以下の式をそれぞれ repro.el に保存し、外部タイムアウトを付けて個別実行します。


`json:cyclic-vector`

```elisp
;;; -*- lexical-binding: t; -*-
(prin1 (let ((v (vector nil))) (aset v 0 v) (condition-case e (json-serialize v) (error (car e)))))
```

GNU: `(ok error)`
Remacs: SIGABRT、stderr に `thread remacs-main has overflowed its stack` / `fatal runtime error: stack overflow`

`json:cyclic-alist`

```elisp
;;; -*- lexical-binding: t; -*-
(prin1 (let ((v (list (cons 'x 1)))) (setcdr v v) (condition-case e (json-serialize v) (error (car e)))))
```

GNU: `(ok circular-list)`
Remacs: 30秒でタイムアウト

`json:cyclic-hash`

```elisp
;;; -*- lexical-binding: t; -*-
(prin1 (let ((h (make-hash-table :test 'equal))) (puthash "x" h h) (condition-case e (json-serialize h) (error (car e)))))
```

GNU: `(ok error)`
Remacs: SIGABRT、stderr に `thread remacs-main has overflowed its stack` / `fatal runtime error: stack overflow`

`json:serialize-depth`

```elisp
;;; -*- lexical-binding: t; -*-
(prin1 (let ((v 0)) (dotimes (_ 1200) (setq v (vector v))) (condition-case e (progn (json-serialize v) 'serialized) (error (car e)))))
```

GNU: `(ok error)`
Remacs: `(ok serialized)`

```sh
./target/debug/remacs -Q --batch -l repro.el
/path/to/emacs-31.1 -Q --batch -l repro.el
```

`src/lisp/builtins/json.rs` の `ser_value` に、再帰深度や処理中オブジェクトの検出がありません。alist の `seen` はキー重複の抑制であり、走査する cons の循環を検出しません。循環しない1200段のvectorでもGNUの深度上限エラーに対しRemacsは成功しました。
