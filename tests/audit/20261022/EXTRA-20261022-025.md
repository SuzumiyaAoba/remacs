削除して取得した文字列が元バッファの multibyte/unibyte を保持しません。また、before-change-functions が削除対象の face を bold から italic に変えても、返る文字列には古い bold が残ります。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64。GNU Emacs 31.1 と各式を独立した新規プロセスで実行して比較。既存 #233 は undo 履歴の属性で、本件は delete-and-extract-region が呼び出し元へ返す文字列の問題です。

## 再現

以下を repro.el に保存します。

```elisp
;;; -*- lexical-binding: t; -*-

;; extract:multibyte-ascii
(prin1 (with-temp-buffer (insert "abc") (let ((s (delete-and-extract-region 1 3))) (list (multibyte-string-p s) (string-to-list s)))))
(terpri)

;; extract:unibyte-high
(prin1 (with-temp-buffer (set-buffer-multibyte nil) (insert (unibyte-string 255 65)) (let ((s (delete-and-extract-region 1 3))) (list (multibyte-string-p s) (string-to-list s)))))
(terpri)

;; extract:properties-after-before-hook
(prin1 (with-temp-buffer (insert (propertize "abc" 'face 'bold)) (let ((before-change-functions (list (lambda (beg end) (put-text-property beg end 'face 'italic))))) (get-text-property 0 'face (delete-and-extract-region 1 3)))))
(terpri)
```

```sh
./target/debug/remacs -Q --batch -l repro.el
/path/to/emacs-31.1 -Q --batch -l repro.el
```

検証結果（ok は式の正常な戻り値）:

`extract:multibyte-ascii`

```text
GNU: (ok (t (97 98)))
Remacs: (ok (nil (97 98)))
```

`extract:unibyte-high`

```text

```

`extract:properties-after-before-hook`

f_delete_and_extract_region は chg_delete 前に属性を保存し、戻り文字列を Value::string で作り直しています。実際に削除した時点の属性とバッファのバイト表現を引き継ぐ必要があります。
