é の正しい UTF-8 は c3 a9 ですが、unibyte バッファに e9 が一バイトで入ります。そのまま保存・送信すると JSON の UTF-8 が壊れます。json-insert は serializer の UTF-8 バイトを保持せず chg_insert_pt に文字列を渡しています。

対象: `38af4d1d720760348e725dac51f8c4252c2b03d5`、macOS/aarch64、GNU Emacs 31.1 と同一コードで比較。`cargo build --offline --bin remacs` 成功。作業ツリーの既存 GUI 変更は保持しています。

## 再現

以下を `repro.el` に保存し、両実装で実行します。

```elisp
;;; -*- lexical-binding: t; -*-

;; json:insert-unibyte
(let ((print-circle t) (print-escape-newlines t))
  (prin1 (condition-case e (list 'ok (with-temp-buffer (set-buffer-multibyte nil) (json-insert "é") (string-to-list (buffer-string)))) (error (list 'error e))))
  (terpri))
```
