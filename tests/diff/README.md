# Differential subr tests (GNU Emacs oracle)

`driver.el` reads `targets.txt` (`NAME|MIN|MAX` rows generated by
`gen_targets.el` under GNU Emacs) and calls every subr with a fixed
deterministic argument corpus, printing `R<idx>|<name>|<status>|<repr>`
rows on stdout.  `tools/difftest.py` runs the driver under both GNU
Emacs and `./target/release/remacs` and diffs the row streams.

    # regenerate the target list (GNU only); use the RAW binary —
    # on this host `emacs' in PATH is a NixOS wrapper that injects
    # --init-directory, which skews `user-emacs-directory'.
    /nix/store/xbihkz9wlccg6ibr96j2qkgindirjs3l-emacs-unstable-31.1/bin/emacs-31.1 \
        -Q --batch -l tests/diff/gen_targets.el -f d--emit \
        > tests/diff/targets.txt

    # run the comparison (defaults --emacs to the raw binary above)
    python3 tools/difftest.py

Divergences land in `tests/diff/report.txt`.  `known.txt` holds
name-level masks for accepted divergences (one symbol name per line).

Protocol notes:

- stderr gets `== <idx> <name>` before each call, so a hang/crash
  blames the last marker.
- Result repr is normalized: opaque objects become "<subr>",
  "<buffer>", "<marker>", ... so reprs compare across ports.
- `quit` is caught (C-g can't fire in batch anyway); `error` records
  (SYM . DATA) normalized.
- Skip list lives in `gen_targets.el` (`d--emit-skip`): process
  control, filesystem mutation, timers, I/O reads, GUI entry points,
  and globals that would corrupt the driver (fset/put/kill-buffer...).
